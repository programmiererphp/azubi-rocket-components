# AZR-D11-C11 — Lokale Inhalte und XML-Konfiguration bearbeiten

Vor Umsetzung festgelegter Vertrag v0.1.0, Referenz AZR-MASTER-FLOW-03/AZR-DETAIL-01..05. Eigenständige native Web Component; keine direkten Imports anderer Feature-Komponenten.

Natives `<azr-content-admin>`, ehrlicher lokaler Inhaltseditor statt unechter Passwort- oder Serveradminsimulation. Hauptanwendung bezeichnet ihn als Einstellungen/lokaler Inhaltsentwurf. Property document {schemaVersion:1,content:{guide,faq,companies,quizzes,resources,letterTemplates},design:{accent,surface,text},layout:{density}}, services.validateDocument. Canonical JSON bleibt intern, XML Import/Export trägt JSON als Textinhalt mit schemaVersion und getrennten Bereichen content/design/layout. DOMParser/Serializer, kein innerHTML, keine DTD/Entities, keine dynamischen Skripte/CSS/URLs. Max5MiB, strukturierte tiefgreifende Validierung durch gemeinsamen Host-Schemavalidierer. Nur erlaubte Hexfarben/density. Text-/Vorlagenbearbeitung für die vier Sprachen und Validierung aller betroffenen Datenverträge. Sichere Firmenkontaktprovenienz erhalten.
JSON-Editor für Inhaltsbereiche mit klaren Abschnittslabels; Feldeditor für Design/Layout. Eigener Vorlagentab de/en/fr/ru. XML hochladen -> validierter Vorschauvergleich/Anzahl -> ausdrücklich anwenden. Vorheriger Zustand für eine Rücknahme. XML-Export tatsächlich herunterladbar, Unicode verlustfrei; fehlerhafte Importe ändern keine aktiven Inhalte. `azr:content-apply {document}`, `azr:content-rollback {document}`, `azr:content-status {status,operation}`. Shell speichert lokale Änderungen; Veröffentlichung an alle Nutzer ist ausschließlich ein späterer überprüfter Git-Deploy, kein vorgetäuschtes Server-Speichern.
Browserprüfungen tatsächliche XML-Datei/Download-Roundtrip, falscheVersion/DTD/Script/ungültigeDatentypen, Preview/Apply/Rollback, locale/Design-Prüfung, Servicefehler, Kopienisolation, 4Locales/3Widths und6Journeylabels. Shell-Regressionsprüfung: geänderte FAQ/Vorlage nach Apply sichtbar; Rücknahme stellt vorigen Zustand wieder her.

Gate: lokal und öffentlich tatsächlich getesteter Browserbuild, Hash-genauer anonymer Download, GitHub-verifizierte Auslieferung vor nächster Implementierung. Privatarchiv bleibt unverändert.

## XML-Schema und Blockimport
Der Editor liefert sein tatsächlich verwendetes XSD sowie das ergänzende tiefe JSON-Datenschema als Downloads. Vollformat `<azr-site schemaVersion="1"><content>JSON-Text</content><design>JSON-Text</design><layout>JSON-Text</layout></azr-site>`. Zusätzlich `<azr-block schemaVersion="1" area="content|design|layout" key="optionalContentSection">JSON-Text</azr-block>` für nacheinander importierbare Inhalts-/Design-/Layoutblöcke. Ein Block wird mit dem bestehenden Dokument zusammengeführt und vollständig validiert, bevor eine Vorschau/Übernahme möglich ist. Keine DTD, Entities, fremden Elemente/Attribute oder scriptfähigen Styles. Fehlender Validierungsservice verhindert Apply, XML Export des vorhandenen validen Hostdokuments bleibt möglich.
