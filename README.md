# Azubi Rocket Web Components

Framework-independent native Web Components with isolated demos, versioned ESM artifacts, manifests and contract/browser tests. Architecture is defined in SPEC.md and COMPONENT_REGISTER.json. Current status is planning; do not infer implementation from mockup references. Legacy material remains outside this public repository. Real app data are injected by the host, public fixtures are synthetic.

All six journey steps must remain visible on every user page, including steps 5 and 6. The host composes components and owns persistence; components do not import each other. No additional license grant is made; repository owner controls reuse/licensing.
