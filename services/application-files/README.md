# Application files service 0.1.0

Local-only certificate PDF merge, safe company CSV, real MIME email draft and application ZIP. CV PDF generation is injected as `exportCv`, so no feature imports or duplicate font/exporter are needed. No network, navigation, sending or private-data logging. Read `OUTCOME_REVIEW_SPEC.md` at repository root for limits, UI obligations and independent parsing acceptance. MIT implementation; pdf-lib1.17.1 and JSZip3.10.1 are pinned. Build produces standalone ESM and SHA256 manifest. No actual legacy contacts or applicant payload belongs in this public repository.
